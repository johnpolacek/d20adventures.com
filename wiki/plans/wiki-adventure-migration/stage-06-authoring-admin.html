Stage 6

Authoring And Admin Workflow

Plan the AI-assisted wiki editor that replaces the current Adventure Plan editor and supports validation, preview, draft, and publish workflows.

Reader Goal

After 2 minutes, know what the authoring product needs before implementation design starts.

Back to plan

Unit 01 - AI-assisted editor model

Define create, expand, rewrite, split page, link NPC, repair validation issue, summarize page, and generate transition tools. Decide human approval gates for AI edits.

Verification

Every AI edit has preview, diff, validation, and accept/reject behavior.

Unit 02 - Admin UX replacement

Inventory current editor features and decide what gets removed, replaced, or folded into a wiki editor and preview surface.

Verification

The final implementation plan can safely delete the current editor without losing required launch capability.

Unit 03 - Draft/publish lifecycle

Define draft S3 files, validation state, publish compilation, rollback, version history, permissions, and preview playthrough behavior.

Verification

Authors cannot accidentally publish invalid adventures or lose draft work.

Unit 04 - Design requirements

Define the authoring UI information architecture: file tree, markdown editor, AI command panel, validation drawer, preview, context graph, and publish status.

Verification

Design brief is updated if durable UI principles change.
