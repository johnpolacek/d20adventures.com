Feature plan

Admin adventure plan chat history

Add a shared authoring chat transcript to the existing S3 JSON Adventure Plan editor so plan managers can revisit prompts, assistant replies, and compact edit-decision events.

Status

State
Implemented
Storage
Convex transcript table
Visibility
Shared by editable Adventure Plan
Boundary
Separate from per-adventure game chat
Unit 01

Persistence and access

Create a Convex table for admin plan chat messages indexed by setting, plan, and creation time. Reads and writes must go through server actions that load the S3 plan/setting and reuse plan-management permission checks.

Unit 02

Assistant workflow

Add server actions that append a user prompt, generate an assistant response using the existing AI SDK wrapper, store optional compact proposal metadata, and record accepted or dismissed suggestion events.

Unit 03

Editor UI

Add an Admin Chat drawer to the Adventure Plan editor with recent history, older-message loading, selected edit scope, prompt submission, and local application of supported text suggestions through the existing save/autosave flow.

Acceptance

  • Authorized plan managers can send an Admin Chat prompt, refresh, and see the prior transcript.
  • Unauthorized users cannot read or write admin chat history.
  • Assistant suggestions can update supported local editor fields without directly writing S3 outside the existing save/autosave path.
  • Game chat remains unchanged and uses its existing chat_messages table.
