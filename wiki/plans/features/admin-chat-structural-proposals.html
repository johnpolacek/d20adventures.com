Implementation plan

Admin chat structural proposals

Extend the Adventure Plan Admin Chat from text-field suggestions to approved structural section, scene, and encounter inserts.

Planned Behavior

  • Add a Plan Structure target that lets assistant replies propose typed JSON operations.
  • Support section, scene, and encounter inserts with complete titles, summaries, encounter intros, and GM instructions.
  • Validate and preview structural proposals before enabling Use.
  • Apply structural proposals to editor state, select the first inserted node, and persist through the existing save action.
  • Prevent the assistant from claiming changes were made before the proposal is applied.

Validation

  • Run TypeScript after implementation.
  • Manually verify a March of Davos Aftermath request produces and applies one section with three scenes and three encounters.
