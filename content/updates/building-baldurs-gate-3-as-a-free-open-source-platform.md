I want to build [Baldur’s Gate 3](https://baldursgate3.game) as a platform.

The gameplay. The implementation of 5E rules. The 3D environments and characters. The battles. The stories. Multiplayer.

Free. Open source. Write and build your own adventures then play them with your friends.

That’s what [d20adventures.com](https://d20adventures.com) is becoming.

I’m keeping track of how far along each part is [here](/vision).

It is a crazy goal. I’ll probably fail.

It will be fun to try.

Would you like to help? The code is [on Github](https://github.com/johnpolacek/d20adventures.com).
